.pet - Petshop

Desafio Extra SCTEC / SENAI-SC

Projeto acadêmico de uma landing page para petshop, desenvolvido com HTML, CSS e JavaScript. A página apresenta a empresa, seus serviços, informações de contato e um formulário com interações básicas em JavaScript.

Tecnologias utilizadas

  • HTML5 - estrutura e semântica da página.
  • CSS3 - estilização, Flexbox, Grid, responsividade e efeitos visuais.
  • JavaScript - validação do formulário, manipulação do DOM e interatividade.

Funcionalidades

  • Carrossel de imagens nativo com HTML e CSS (scroll-snap).
  • Navegação suave (smooth scroll) entre seções.
  • Menu mobile recolhível em telas menores.
  • Formulário de contato com validação e interatividade customizada via JS.
